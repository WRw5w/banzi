# 板子重写版

本目录是从 `合订本.pdf` 重构出的新版本源文件。

## 文件

- `第一本_现场速查.tex`：比赛现场速查版，末尾包含压缩后的错题附录。
- `第二本_详细验证.tex`：详细解释、接入说明和验证样例。
- `preamble.tex`：两本手册共用的排版配置。
- `chapters/`：两本手册的章节源文件。
- `../muban.cpp`：复制算法板子前统一使用的代码地基；本目录不再维护副本。

## 章节目录

两本手册共用以下主章节源，编号就是 PDF 中的阅读顺序：

1. `00_总览.tex`：使用说明、代码地基、复杂度速查和关键词索引；
2. `01_基础数据结构.tex`：基础数据结构与常用技巧；
3. `02_图论与树.tex`：图论、树和网络流；
4. `03_字符串.tex`：KMP、AC 自动机、后缀结构等；
5. `04_数学与DP.tex`：数学、动态规划和几何基础；
6. `05_银牌高频.tex`：莫队、可持久化结构、树上高级模板等；
7. `06_错题附录.tex`：第一本末尾的压缩错题本（第二本不重复收录）。

第一本按“总览 → 基础 → 图论与树 → 字符串 → 数学与 DP → 银牌高频 → 错题附录”生成。
第二本在开头增加不占编号的验证协议，正文使用同一套章节源，末尾增加专项验证记录，避免两本代码漂移。

## 重构约定

每个模板都从仓库根目录的 `muban.cpp` 复制后追加。算法卡片只写相对于地基的额外结构、初始化、调用和样例，不重复整套基础头。

代码注释统一按四层写：

- 结构层：数组、节点、边和状态分别表示什么；
- 不变量层：循环或递归过程中始终成立的条件；
- 接口层：初始化、调用参数、下标约定和返回值；
- 排错层：最容易抄错、溢出、忘记清空或误用的地方。
