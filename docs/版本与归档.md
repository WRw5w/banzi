## 发布规则

1. 只编辑 `banzi/板子_大版本.tex` 及其引入的 `remake/large/*.tex`；
2. 正式产物始终覆盖 `banzi/板子_大版本.pdf`；
3. 修改模板后运行接口、变量和代码块覆盖审计、框架结构契约、门禁反例单测、正式
   代码块契约/差分测试及六组 `tests/refactored_*.cpp` 回归测试；验证状态不写入正式板子；
4. 使用 `python tools/build_formal_pdf.py` 在隔离目录持续运行 XeLaTeX，直到目录、
   书签和交叉引用状态稳定且没有 rerun warning，再目视检查受影响页面；
5. 不创建现场版、详细版、完整版、含例题版、最终版等并列入口或 PDF；
6. 必须保留里程碑时，只复制到 `archive/YYYY-MM-DD/`，文件名写明来源提交和页数；
7. 源文件、测试、正式 PDF 和本文档在同一个提交中同步，并推送 `origin/main`。
