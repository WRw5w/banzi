## 发布与归档规则

1. 修改大版本时只编辑 `banzi/板子_大版本.tex` 和它引入的 `remake/large/*.tex`；
2. 编译时连续运行两遍 XeLaTeX，正式产物始终覆盖 `banzi/板子_大版本.pdf`；
3. 发布前运行接口审计、变量审计和 `tests/refactored_*.cpp` 六组回归测试；
4. `banzi/` 中不再创建“完整版”“含例题”“最终版”等并列变体；
5. 必须保留里程碑时，复制到 `archive/YYYY-MM-DD/`，文件名写明来源提交和页数；
6. 源文件、测试、正式 PDF 和归档说明在同一个 Git 提交中同步，并推送 `origin/main`。

`new/`、`big-anwser/` 和 `output/pdf/` 保存重构过程资料，不是当前正式大版本的输入源。
