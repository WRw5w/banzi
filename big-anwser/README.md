# 区域赛银牌 / Codeforces ≤ 2200 算法大全

这是一套面向 ICPC/CCPC 区域赛银牌线、Codeforces 约 2200 分以下题目的完整 C++ 竞赛算法知识库。目标不是背板子，而是建立“**看到约束 → 识别模型 → 选择算法 → 证明正确 → 控制复杂度**”的完整链路；遇到生僻算法时，可以直接在模板库中检索并复制。

## 覆盖边界

- **必会**：Codeforces 1200–1900、区域赛银牌大部分基础题与中档题。
- **应会**：Codeforces 1900–2200 中高频模型，以及区域赛需要组合多个基础算法的题。
- **了解**：2200 以上但常作为银牌题中的一个子步骤的算法（如点分治、CDQ、SAM 的基础用法）。
- 不包含需要复杂数据结构证明、重型多项式/生成函数、复杂博弈理论等通常高于 2200 的完整体系；相关内容在“进阶专题”中给出识别与入门模板。

## 推荐使用方式

1. 先读总览，按路线完成每一层；不要一开始从最难专题开始。
2. 每学一个算法，至少完成：手写核心代码、说出不变量、做 3 道不同变形题。
3. 训练时先看 [题型索引](09-题型索引.md)，用约束和关键词定位模型，再回到专题页复习。
4. 模板只解决实现，不替代建模。提交前检查下标、溢出、清空全局变量、图是否有重边/自环。

## 总体能力清单

- [ ] 复杂度估算：从 `n` 判断 `O(n) / O(n log n) / O(n√n) / O(n²)` 是否可行。
- [ ] 前缀和、差分、双指针、二分答案、离散化、坐标压缩。
- [ ] 排序贪心、反悔堆、区间调度、交换论证、构造与不变量。
- [ ] 质因数分解、筛法、扩展欧几里得、逆元、组合数、快速幂、矩阵快速幂。
- [ ] BFS/DFS、拓扑排序、Dijkstra、0-1 BFS、Bellman-Ford/SPFA 的适用边界。
- [ ] Kruskal/Prim、并查集、割点桥、强连通分量、二分图匹配/染色。
- [ ] 树上 DFS、LCA、树上差分、直径、重心、树形 DP、倍增。
- [ ] 线性/区间/背包/树形/状压/数位/概率 DP，滚动数组与单调队列优化。
- [ ] 树状数组、线段树（懒标记、扫描线）、ST 表、堆、Trie、哈希表。
- [ ] KMP、Z、字符串哈希、Manacher、AC 自动机；能判断是否需要后缀结构。
- [ ] 凸包、叉积判向、点线关系、旋转卡壳；浮点误差与 `eps`。
- [ ] 分治、CDQ/整体二分、点分治、虚树、随机化、位运算与 SOS 思想。

> 约定：文档中的复杂度默认使用 `n` 表示规模，`m` 表示边/询问数，`V,E` 表示图的点数/边数；所有 C++ 代码以 C++17 为准。
