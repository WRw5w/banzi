# 02. 数学与数论

## 1. 模运算与快速幂

对质数/任意模数都成立：`(a+b)%p`、`(a-b+p)%p`、`a*b%p`。除法不能直接取模，必须证明逆元存在。

```cpp
long long qpow(long long a, long long e, long long mod) {
    a %= mod; long long r = 1 % mod;
    while (e) {
        if (e & 1) r = (__int128)r * a % mod;
        a = (__int128)a * a % mod; e >>= 1;
    }
    return r;
}
```

费马小定理：`a^(p-1) ≡ 1 (mod p)`（`p` 质数且 `p ∤ a`），逆元为 `a^(p-2)`。欧拉定理推广到 `gcd(a,m)=1`：`a^φ(m) ≡ 1 (mod m)`。

## 2. 最大公约数、扩展欧几里得与同余

```cpp
long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (!b) { x = 1; y = 0; return a; }
    long long x1, y1, g = exgcd(b, a % b, x1, y1);
    x = y1; y = x1 - (a / b) * y1; return g;
}
```

解 `ax ≡ b (mod m)`：令 `g=gcd(a,m)`，若 `b%g!=0` 无解；否则约去 `g`，用扩展欧几里得求一个解，通解模 `m/g`。

中国剩余定理（互质模数）：`x = Σ ai * Mi * inv(Mi mod mi) mod M`。非互质模数用“合并两个同余方程”：检查差值能否被 `gcd` 整除，再扩展欧几里得求增量。

## 3. 质数与筛法

### 3.1 试除与质因数分解

试除到 `i*i<=n`，每次除尽；单个 `n≤1e12` 适用。若只需判质数，复杂度 `O(√n)`。

### 3.2 埃氏筛与线性筛

埃氏筛复杂度 `O(n log log n)`；线性筛保证每个合数只被最小质因子筛一次，复杂度 `O(n)`，可同时求 `phi`、莫比乌斯等积性函数。

```cpp
vector<int> primes, lp(N), phi(N);
phi[1] = 1;
for (int i = 2; i < N; ++i) {
    if (!lp[i]) lp[i] = i, primes.push_back(i), phi[i] = i - 1;
    for (int p : primes) {
        if (p > lp[i] || 1LL * i * p >= N) break;
        lp[i * p] = p;
        if (p == lp[i]) phi[i * p] = phi[i] * p;
        else phi[i * p] = phi[i] * (p - 1);
    }
}
```

### 3.3 约数枚举与整除分块

枚举约数成对出现，`O(√n)`。对 `floor(n/i)` 的求和，商相同的 `i` 区间为 `[i, n/(n/i)]`，可在 `O(√n)` 个块内完成（数论分块）。

## 4. 欧拉函数、莫比乌斯与积性函数

`φ(n)=n∏(1-1/p)`。求单点先分解；求前缀用线性筛。

莫比乌斯函数：`μ(1)=1`，含平方因子为 0，否则质因数个数奇偶决定 ±1。常见反演：若 `f(n)=Σ_{d|n}g(d)`，则 `g(n)=Σ_{d|n} μ(d)f(n/d)`。

## 5. 组合数与阶乘

### 5.1 质数模且 `n` 不大

预处理 `fac[i]`、`ifac[i]`，`C(n,k)=fac[n]ifac[k]ifac[n-k]`，预处理 `O(N)`，查询 `O(1)`。

### 5.2 卢卡斯定理

质数 `p` 下：`C(n,k) ≡ ∏ C(n_i,k_i) (mod p)`，其中 `n_i,k_i` 是 `p` 进制位。适用于 `n` 很大、`p` 较小。

### 5.3 非质数模

分解模数的质数幂，计算每个质数幂下的阶乘（跳过 `p` 因子），再用 CRT 合并。实现复杂且容易错，只有题目明确需要时使用。

## 6. 矩阵与线性递推

线性递推 `f(n)=c1 f(n-1)+...+ck f(n-k)` 可转为 `k×k` 矩阵快速幂，复杂度 `O(k³ log n)`；Fibonacci 为 `2×2`。矩阵乘法注意模乘溢出。

## 7. 容斥与组合计数

全集计数减去至少一个坏条件。`n≤20` 时枚举子集：

`ans = Σ (-1)^{|S|} count(同时满足 S 中条件)`。

条件独立/按质因子分解时可用容斥；条件数量大时优先找补集、莫比乌斯反演或 DP。

## 8. 概率、期望与博弈

- 期望线性：`E[X+Y]=E[X]+E[Y]`，即使不独立也成立。
- 终止状态递推：`E[state]=1+Σ p_i E[next_i]`；若有自环移项并检查系数非零。
- Nim：多堆石子异或和为 0 是必败态；Sprague-Grundy 值为各子游戏 xor。
- 取模概率需要模逆；分母与模数不互质时不能直接除。

## 9. 常见数列与技巧

- 等差/等比求和、前缀异或（周期 4）、`1 xor ... xor n`。
- `gcd(a,b)=gcd(a,b-a)`；`lcm(a,b)=a/gcd(a,b)*b`。
- 斐波那契 gcd：`gcd(F_m,F_n)=F_gcd(m,n)`（用于识别构造题）。
- 反复应用 `x -> x/gcd(x,a)` 时，质因数分解通常比模拟更快。
