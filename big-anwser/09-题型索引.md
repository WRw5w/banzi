# 09. 题型/关键词 → 算法索引

本页用于“想不起算法名，但记得题面特征”的快速检索。括号内为优先阅读的文件。

## 约束驱动

| 题面规模/条件 | 首选 |
| --- | --- |
| `n≤20`，选或不选 | 状压/子集枚举 |
| `n≤40`，求和/最值 | 折半搜索 |
| `n≤200`，区间分割 | 区间 DP / `O(n³)` |
| `n≤2000`，二维关系 | `O(n²)` DP、朴素图 |
| `n≤2e5`，静态区间 | 前缀和、ST、离线排序 |
| `n,q≤2e5`，动态区间 | 树状数组/线段树 |
| `n` 可到 `1e18` | 数论、矩阵快速幂、数位 DP |
| 字符串总长 `≤1e6` | KMP/Z/AC/线性筛式算法 |

## 数组与区间

- “连续子数组和/平均值”：前缀和；要求正数且窗口合法：双指针；要求最短和：前缀和 + 单调队列。
- “最小的最大值/最大的最小值”：二分答案。
- “区间加、最后统一询问”：差分；“边加边查前缀”：树状数组。
- “区间最值、静态”：ST；“区间修改 + 区间查询”：线段树。
- “下一个更大/更小”：单调栈；“窗口最值”：单调队列。
- “逆序对/动态排名”：树状数组或归并排序。
- “离线询问，区间增删可维护”：莫队。
- “第 k 小”：主席树、整体二分、值域线段树。

## 贪心与构造

- 区间最多不相交：按右端点排序。
- 合并代价最小：小根堆/Huffman。
- 有截止时间的最多任务：排序 + 反悔堆。
- 每步选局部最优且交换不变差：写交换论证。
- “无解/必有解”：检查奇偶、模数、总和、连通性、度数不变量。

## 数论

- 单点质因数：试除；批量质数/欧拉函数：线性筛。
- 大指数：快速幂；线性递推：矩阵快速幂。
- 模意义除法：扩展欧几里得/费马逆元；模数不质数先检查互质。
- 组合数：阶乘逆元；`n` 极大、模数质数：Lucas。
- 多个同余方程：CRT/扩展 CRT。
- “所有约数/`floor(n/i)`”：约数枚举/数论分块。
- “至少一个条件”：容斥；整除和式：莫比乌斯反演。

## 图论

- 无权最短路：BFS；边权 0/1：0-1 BFS；非负权：Dijkstra。
- 负边：Bellman-Ford；全源小图：Floyd；DAG：拓扑 DP。
- 连通块/在线合并：DFS/BFS/DSU。
- 最小连接代价：Kruskal/Prim。
- “有向环、互相可达”：SCC 缩点。
- “删点/删边使图断开”：割点/桥/最小割。
- “两类点不能同组”：二分图染色；“最多配对”：匹配。
- “资源容量/冲突/分配”：最大流、最小割、费用流。
- “选项二选一且有冲突”：2-SAT。
- “依赖顺序”：拓扑排序。
- “树上路径”：LCA/HLD；“树上子树”：DFS 序；“所有点距离和”：换根 DP。
- “树上两点距离/点对计数”：直径、点分治、虚树。

## DP

- “每个物品选/不选”：0/1 背包；可重复：完全背包。
- “最后一步决定答案”：线性 DP；“左右端点逐渐缩短”：区间 DP。
- “树没有环”：树形 DP；“有先后关系”：DAG DP。
- “数字不超过 N”：数位 DP。
- “少量元素的集合关系”：状压 DP。
- “转移窗口固定”：单调队列；“决策点单调”：分治优化；“直线转移”：斜率优化/Li Chao。
- “胜负状态”：SG/博弈 DP。

## 字符串

- 单模式匹配：KMP/Z；重复前缀/周期：前缀函数。
- 多模式：AC 自动机。
- 子串相等/二分 LCP：哈希；最长回文：Manacher。
- 不同子串/重复子串：后缀数组 + LCP 或 SAM。
- 动态回文后缀：回文自动机。
- 循环同构最小表示：Booth。

## 常见算法组合

1. 离散化 + 树状数组：排名、逆序、区间计数。
2. DFS 序 + 线段树：子树修改/查询。
3. LCA + 树上差分：大量路径经过次数。
4. SCC 缩点 + DAG DP：有向图上的可达/最大权。
5. 二分答案 + BFS/贪心/流：判定型最优化。
6. Kruskal 重构树 + 倍增：按边权阈值查询连通块信息。
7. AC 自动机 + DP：避免模式/统计匹配串。
8. 主席树 + LCA：树上路径第 k 小。
9. 扫描线 + 线段树 + 坐标压缩：矩形并、覆盖次数。
10. 回滚 DSU + 线段树时间分治：离线动态连通性。
