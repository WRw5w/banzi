\section*{统一检查顺序}
\addcontentsline{toc}{section}{统一检查顺序}
\begin{enumerate}
\item 按 \texttt{g++ -std=c++17 -O2 -Wall} 编译；
\item 跑完整样例，核对题面变量到接口的映射；
\item 跑空、单点、重复、无解四类最小反例；
\item 多测重建对象或调用 \texttt{init()}，再做随机对拍。
\end{enumerate}

\chapter{专项验证记录}
\section{高风险模板}
\begin{itemize}
\item AC 自动机：总出现次数与每个模式串出现次数分别验证，覆盖后缀模式和重复模式；
\item SAM/PAM/后缀数组：覆盖空串、单字符、全相同字符串和克隆/重复回文；
\item 线段树、持久化线段树、DSU on Tree：覆盖整段标记、版本差异和多测清空；
\item 图论与 CHT：覆盖不可达、重边、自环、负边禁用条件和单调性条件。
\end{itemize}
